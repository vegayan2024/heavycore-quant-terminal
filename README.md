# 「重器」周期反转与细分国企隐形冠军·量化投研终端
> **HeavyCore Quant Terminal (V3.5)**  
> *“国之重器，周期磐石” —— 专注于大国制造、顺周期供给侧出清与央国企细分龙头的机构级投研决策系统。*

---

## 📌 项目定位与核心理念

本系统将**周期反转大级别交易体系**与**对外经贸大学张新民教授财务报表分析体系（八看、核心利润、四大动力、两头吃能力）**深度结合，借鉴 **大包子财报终端 (terminal.shengfund.cn)** 的机构级研报架构与 **Hallmark 护眼设计规范**，专为解决周期股“底部选股难、估值反常识、震荡易踏空、卖点无闭环”等痛点打造。

## 🌟 核心功能模块

1. **三票否决与 100 分制量化打分盘**：
   * 财务安全底线、需求非衰退、PB 绝对低估一票否决。
   * 核心驱动项（60分）与辅助催化项（40分）实时联动，自动输出推荐仓位（0仓 / 底仓 / 中仓 / 重仓）。
2. **张新民教授财报质量深度诊断**：
   * 自动核算**核心利润与同口径获现率**。
   * 细拆**四大动力构成**（经营负债、金融负债、股东入资、利润积累）与母公司控制性投资扩张倍数。
   * 量化判定上下游**“两头吃”定价能力**（存货 vs 应付，商业债权 vs 商业债务）。
   * 综合**八看质量雷达图**与**行业平均/中位数对标矩阵**。
3. **高频供需与产能价格联动图表**：
   * 产品-原料“剪刀差”高频趋势图（单位毛利阴影面积）。
   * 产能利用率（公司开工率 vs 行业平均）逆势抢份额展示。
   * 库存周期四象限定位钟（精确定位被动去库黄金买点）。
4. **60/40 仓位物理隔离与双轨退出控制台**：
   * **60% 锁定底仓**：模式 B 三阶梯止盈（+85% 达成回本锁、PB 极端泡沫、产业复产见顶）。
   * **40% 浮动波段仓**：模式 A 网格降成本（+30%/+50% 减利润、回调 $\ge 15\%$ 结合价差健康触发回补）。
   * **非线性弹性模拟器**：拖动产品涨幅与成本跟随率，实时输出经 0.75x 安全折扣后的目标市值与赔率倍数。
5. **一键切换大包子/ShengFund 机构级深度研报**：
   * 顶部无缝切换为排版精美、层次清晰、适合打印导出的深度投研报告。

## 🚀 启动与使用

本程序采用纯原生现代 ES Modules 架构，**零依赖、秒级响应**：
1. **直接打开**：在文件浏览器中双击进入 `heavycore-quant-terminal/index.html` 即可。
2. **本地服务器**：亦可在本目录下运行 `python -m http.server 8000` 或 VS Code Live Server 启动。
